# 결정 대기 목록

답변 전에는 아래 내용을 게임 규칙으로 확정하지 않는다.

## 먼저 논의할 내용

1. 엔진 선택과 첫 시제품의 개발 범위.
2. 베이비 울음을 멈추는 조건과 마더를 피하는 방법, 플레이어 발견 시 추적 방식.
3. 문을 닫았을 때 전력 소모량, 다른 장치의 전력 소모 여부와 수리 조작.
4. 라디오 주파수와 할머니의 파동 규칙.
5. 테니스공 카메라 안정화와 감정표현의 구체적인 연출.
6. 높은 난이도의 부활 횟수, 개인·팀 공유 여부, 전멸·영구 사망 후 관전 규칙.

## 사용자 답변으로 확정된 내용

- 한 판 15분.
- 문으로 관제실 방어. 외부에서 두꺼비집·깨진 라이트 수리와 물자 회수.
- 관제실 파괴 또는 전기 용량 소진 시 다른 관제실로 이동.
- 베이비의 목소리 모방·놀래키기, 밀치거나 때리면 울음.
- 울음으로 마더 각성. 마더는 문·라이트 파괴, 포획 시 부활 불가.
- 모든 캐릭터 칠판·감정표현 가능. 공은 굴리기만 가능, 들기·던지기 불가.
- 7초 키 유지로 부활. 쉬움은 무제한, 상위 난이도는 제한. 부활 후 손상 외형 유지.
- 소년 인형 이름: 풋보이 (Foot Boy). 독자적 외형 제작 동의.
- 마더는 베이비 울음 방향으로 이동하며 모두를 공격. 울음이 끝나면 현재 위치에서 잠듦.
- 문을 닫으면 전력 소모. 일시적인 정전은 수리 가능하지만 소진된 용량은 복구 불가.
- 공은 바닥에서 굴러도 라디오·할머니와 같은 시점 높이 유지. 칠판에서는 매직이 떠서 움직임.

## 구현 전에 정할 내용

- 엔진과 버전: 아직 선택하지 않음. 설치된 도구 확인과 후보 검토 후 사용자와 결정.
- 라디오 주파수: 플레이어별 채널인지, 괴물별 채널인지, 여러 소리를 동시에 수신 가능한지.
- 할머니의 파동: 범위, 지속시간, 벽 투과 여부, 지팡이 소리가 괴물을 유인하는지.
- 테니스공: 시선 회전 방식, 굴러갈 때 카메라 회전과 멀미 대응.
- 음성: 게임 내 음성 사용 여부 및 제약 적용 방식.
- 온라인 접속: 스팀 초대, 로비, 호스트 종료·접속 끊김·재접속 처리.
- 각 캐릭터 한 명씩 필수인지, 4명 미만 플레이를 지원하는지.
- 칠판 그림의 네트워크 공유 및 삭제 규칙.
- 먹이사슬이 세계관 설명인지, 괴물끼리 상호작용하는 실제 시스템인지.
- 맵 규모, 밤별 난이도, 콘텐츠 분량, 목표 출시 일정과 예산.
