# 진행 기록

## 2026-10-07

- 사용자가 지정한 GitHub 저장소를 로컬 프로젝트에 연결. 원격 저장소는 비어 있었음.
- 사용자 기획을 게임 기획 문서에 기록.
- 확정된 설정, 미정 질문, 검토용 개발 단계를 구분.
- BOMBANANA!의 스팀 소개에서 감각 제약에 기반한 협동 참고점을 확인.
- 게임 코드와 디자인 에셋은 아직 생성하지 않음. 핵심 질문에 대한 답변 이후 구현 방향 결정.

### 추가 기획 답변 반영

- 한 판 15분, 문 방어, 외부 수리·회수, 관제실 전력 소진과 이동을 기록.
- 베이비의 방해 행동과 울음, 마더 각성·파괴·부활 불가 규칙을 기록.
- 칠판·감정표현 공통 사용, 테니스공은 굴리기만 가능함을 기록.
- 7초 부활, 난이도별 횟수, 부활 후 손상 외형을 기록.
- 소년 인형 이름을 풋보이로 확정. 세부 외형은 미정으로 유지.

### 생존 규칙 추가 확정

- 마더는 울음 방향으로 이동하며 모든 플레이어를 공격하고, 울음 종료 시 현재 위치에서 잠듦.
- 문을 닫으면 전력 소모. 수리 가능한 일시 정전과 복구 불가인 용량 소진을 구분.
- 테니스공은 같은 시점 높이를 유지하고, 칠판 사용 시 매직이 떠서 움직이는 연출 승인.

### 감각과 베이비 진정 규칙

- 베이비를 들고 흔들어 달래는 행동과 자연 울음 종료를 기록. 자연 종료 40초는 사용자 제안값으로 남김.
- 모든 소리를 수신하는 하나의 정답 주파수와 무작위 변경·재조정을 기록.
- 벽 너머 파동 시야, 청각형 괴물의 지팡이 반응과 마더의 이동 없는 시선 이스터에그를 기록.
- 달래는 시간·가능한 캐릭터, 주파수 변경 간격, 파동 수치 등은 임의 확정하지 않음.

### 이동과 달래기 추가 규칙

- 베이비를 달래면서 걷기 가능, 달리기 불가. 테니스공은 달래기 불가.
- 스태미나 고갈 시 달리기 불가, 이동속도는 토끼 > 라디오 > 할머니 순서로 기록.
- 사용자 지정 무작위 15~25초는 적용 대상 확인 대기. 자연 울음 시간과 달래는 시간을 임의로 동일하게 정하지 않음.

### 베이비 시간 확정

- 사용자 확인: 안고 흔들어 달래는 시간은 무작위 15~25초.
- 달래지 않은 울음은 40초. 마더는 베이비 울음 종료 시 잠드는 기존 규칙을 따름.
- 시간 적용 대상에 대한 미정 항목을 해소.

### Unity 제작 시작

- 사용자 요청으로 Unity 제작 시작. 설치 확인 결과 Unity가 없었고 사용자도 미설치를 확인.
- 로컬 테스트 공간 생성, 네 역할 전환, 이동·스태미나·카메라 높이, 주파수 데이터와 임시 검은 화면 시야 테스트 소스 작성.
- 개발용 수치는 임시값으로 명시. 실제 파동·음성·멀티플레이·공 물리와 생존 규칙은 후속 구현.
- 에디터가 없어 컴파일·실행 검증은 대기. Unity Hub 설치 시작.
- winget이 Unity Hub 설치 성공을 보고했고 설치 목록에서도 확인됨. 실행 파일 위치는 아직 확인하지 못함. 에디터 설치·라이선스 활성화·실행 검증은 완료되지 않음.

### 첫 에디터 검증

- Unity Hub가 MSIX 앱 패키지로 설치되어 일반 프로그램 경로에서 찾지 못했던 사실을 확인.
- 사용자가 에디터 설치 완료를 알림. Unity 6000.6.4f1 설치와 라이선스 확인 성공.
- 배치 모드에서 코드 컴파일과 LocalTest 장면 생성 성공, 종료 코드 0 확인.
- 생성된 장면, 에셋 GUID 메타 파일, 패키지 잠금과 프로젝트 설정을 저장.
- Unity 에디터로 프로젝트를 열도록 실행. 실제 플레이·화면 검증은 아직 미완료.

### 첫 네트워크 테스트

- 최대 4인 LAN 호스트·참가, 임시 역할 배정, 서버 이동·스태미나, 공 물리와 밀기 코드 작성.
- Netcode 2.13.3으로 Unity 6.6 호환성 확인. 실행 시 네트워크 설정 초기화 오류 수정.
- Windows 실행 파일 생성. 동일 PC에서 호스트 + 참가자 3개 실행 테스트 PASS.
- 서버의 4개 고유 역할·원격 입력·수평 이동과 각 클라이언트의 위치 복제 확인. 테스트 충격에 따른 공 물리 복제 확인.
- 화면·사람의 실제 플레이·외부 접속·지연은 아직 검증하지 않음. 음성·실제 파동과 생존 시스템은 후속 작업.

### 사용자 접속 확인

- 사용자가 같은 PC에서 게임 창 5개를 실행하여 첫 4개 접속과 5번째 접속 차단을 확인.
- 라디오 → 할머니 → 토끼 → 테니스공 역할 배정도 사용자가 확인.
- 이 확인은 실제 사람 4명의 협동 플레이나 다른 PC·외부 네트워크 테스트를 의미하지 않음.

### 핑크색 재질 수정과 테스트 역할 변경

- 사용자가 전체 공간이 핑크색으로 보이는 화면을 제공. 이전 자동 테스트가 그래픽 없는 실행이어서 시각 오류를 잡지 못했음.
- 빌드에 포함되는 명시적인 테스트 셰이더와 재질로 교체. 실제 D3D11 캡처에서 핑크 오류 픽셀 0, 바닥·벽·선반을 시각 확인.
- 사용자 요청에 따라 1~4 키 역할 변경과 점유 역할 교환 구현. 서버 권한 처리 및 카메라·물리 상태 갱신.
- 역할·거리 디버그 라벨 추가. 두 창으로 공 굴리기를 확인할 수 있도록 지원.
- 두 플레이어 역할 변경·교환·카메라 높이·복제 자동 테스트 PASS.
- 수정된 실행 파일은 Builds/NetworkTest-02에 보관하여 이전 실행 파일과 구분.
- 수정 후 기존 호스트 + 참가자 3개 이동·공 물리 복제 자동 테스트도 PASS.

### 몸으로 공 밀기·벽 반동·시점 회전

- 사용자 요청: E 굴리기 제거, 몸 밀기만 유지. 벽 반동과 마우스 시점 회전 오류 수정.
- 몸 충돌의 밀기 속도를 플레이어 이동 속도에 연결. 높은 프레임에서 최소 이동거리 때문에 이동이 무시되던 문제를 고정 물리 업데이트와 최소 거리 0으로 해결.
- 마찰·감속을 낮추고 연속 충돌 검출 적용. 벽 법선 방향 반동은 충돌 직전 속도의 0.8로 설정한 임시 테스트 값.
- 마우스는 접속 시 자동 포착, Esc 해제·클릭 재포착, 포커스 전환 처리 추가.
- 실제 물리 테스트 PASS: 몸 접촉으로 밀기, 속도 2/6/14 벽 반동. 측정된 충돌/반동 속도는 약 1.771/1.416, 5.846/4.677, 13.864/11.091.
- 카메라 회전과 상하 제한 계산 PASS. 실제 마우스 움직임과 창 전환은 사용자 확인 대기.
- 수정 후 4인 이동·공 복제 및 2인 역할 교환 테스트 PASS. 최신 실행 파일은 Builds/NetworkTest-03.

### 사용자 수정 결과 확인

- 사용자가 새 버전의 몸 밀기·벽 반동·마우스 회전 수정에 대해 정상 작동을 확인함.
- 기본 이동·공 협동 시제품의 수동 확인 완료. 최종 수치 조정과 실제 4인 플레이 테스트는 별도로 진행한다.

### 2026-10-07 인게임 음성 및 할머니 파동

- 사용자 승인에 따라 자동 감지·V키 누르고 말하기, 설정 저장·마이크 선택·음소거 구현.
- LAN PCM16 음성 스트림과 공간 청취. 라디오 정답 주파수의 거리 제한 없는 청취, 토끼 송신 차단을 서버에 적용.
- 할머니 검은 화면에 지팡이·발걸음·목소리의 확산 파동 및 벽 너머 윤곽 구현. 임시 전체 시야 열기 제거.
- 컴파일/Windows 빌드 성공. 무음·지팡이·목소리 실제 GPU 캡처 확인, 핑크 오류 픽셀 0.
- 합성 음성 네트워크 통합 검증 PASS. 실제 마이크를 열지 않는 테스트로 전송·파동·토끼 차단·지팡이 역할 제한을 검사. 실제 장치 청취는 사용자 확인 대기.
- 실행 파일 Builds/NetworkTest-04. 괴물 음성·마더 반응은 아직 미구현.
- 추가 후 기존 테스트도 PASS: 4인 이동·공 물리 동기화, 2인 역할 교환, 몸 접촉·벽 반동·시점 계산.

### 사용자 피드백 조정: 공·지팡이·음성 설정

- 공 카메라는 물리 회전과 분리해 LateUpdate에서 월드 위치·시선을 유지. 마우스 시선만 변경.
- 사용자 요청에 따라 토끼 < 공 < 할머니 시점으로 변경. 임시 높이는 0.65/0.95/1.5m. 공 반지름 0.65m로 외형과 물리 충돌 크기를 함께 확대.
- 지팡이 재사용 대기시간 10초를 서버에서 적용하고 남은 시간 표시. 역할 변경으로 대기시간 초기화 불가.
- 발걸음 파동: 이동 0.85m마다 → 1.8m마다, 범위 6m → 2.5m, 지속 0.3초 → 0.12초, 강도 0.8 → 0.22. 지팡이는 기존 강한 윤곽 유지. 이 수치는 사용자 확인 후 조정할 임시값.
- 음성 설정에 마이크 증폭 1~10배, 수신 음량 0~100%, 자동 감지 임계값 조절 추가. 증폭은 송신 전 적용하므로 작은 목소리의 전달·자동 감지·파동에도 반영.
- 할머니 기존 파동 구현은 사용자 확인 완료. 실제 마이크 품질은 추가 확인 필요.
- 사용자 추가 설명에 따라 위 발걸음 1.8m 간격 조정은 취소. 각 발걸음 소리 이벤트마다 한 번 퍼지고 청취 거리에서 끝나는 파동으로 변경. 예시 2m 발걸음/3m 목소리를 임시 테스트 범위로 공유. 목소리는 연속 파동 대신 발화 시작 한 번, 0.35초 이상 멈춘 후 재발화 시 새 파동. 거리 밖 일반 음성은 선형 감쇠로 차단, 라디오 정답 주파수는 무제한 청취 예외.
- 자동 검증 PASS: 10초 지팡이 제한·재충전, 공 카메라 회전 독립·높이·크기, 마이크 증폭, 음성 전달·토끼 차단. 확대된 공의 몸 밀기·속도 비례 벽 반동과 2인 역할 교환도 PASS.
