# 개발 단계 — 검토용 제안

아래 순서는 개발 작업을 나누기 위한 제안이다. 구체적인 엔진, 규칙, 일정과 비용은 승인 전 미정이다.

1. 기획 정리: 핵심 생존 규칙과 네 캐릭터의 협동 방식 결정.
2. 기술 시제품: 단순한 공간에서 네 플레이어 접속, 역할별 감각, 테니스공 이동·물리 동기화 검증.
3. 한 판 시제품: 관제실, CCTV, 공유 칠판, 첫 괴물, 밤 진행, 죽음·부활 구현.
4. 플레이 테스트: 네 명이 실제로 협력할 이유와 공포·답답함의 균형 확인.
5. 디자인 제작: 승인된 콘셉트로 모델, 애니메이션, 조명, 소리, UI 제작.
6. 콘텐츠 확장: 추가 괴물, 공간과 난이도. 범위는 테스트 결과를 보고 결정.
7. 출시 준비: 온라인 안정성, 성능, 옵션·접근성, 스팀 연동, 스토어 자료, 배포 검증.

첫 기술 시제품의 목표는 완성 그래픽이 아니라 가장 어려운 협동·물리·감각 제한이 실제로 동작하는지 확인하는 것이다.
