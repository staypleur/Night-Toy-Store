# Night Toy Store

스팀 출시를 목표로 개발하는 4인 협동 1인칭 공포게임.

밤의 장난감 가게에서 서로 다른 감각과 이동 제약을 가진 네 장난감이 협력하여 22:00부터 08:00까지 생존한다.

## 현재 상태

Unity 6000.6.4f1에서 로컬 테스트와 LAN 네트워크 테스트를 구현했다. Windows 빌드와 동일 PC의 호스트 + 클라이언트 3개 자동 테스트로 역할 배정, 원격 입력·이동 동기화, 공 물리 동기화를 확인했다. 실제 사람 4명의 플레이, 화면·외부 네트워크 검증과 최종 디자인은 아직 완료되지 않았다.

사용자가 승인한 설정과 개발자의 제안을 구분한다. 미정인 게임 규칙과 디자인을 임의로 확정하지 않는다.

최신 시제품: `Builds/NetworkTest-08/NightToyStore.exe`. Space로 라디오·할머니·토끼 점프, 할머니 지팡이는 Q. 공은 점프 불가이며 일반 공격 면역/즉사 예외의 서버 판정 기반을 추가했다. 괴물 공격과 부활은 아직 미구현이다. 실행 방법과 검증 범위는 시제품 문서를 참고한다. 실제 마이크 확인은 추후 두 PC에서 진행한다.

08 맵은 사용자 그림 기반 고정 구조다. 시작 관제실만 무작위, 네 명 함께 시작. 관제실 10×10m와 좌우 문·창문·카메라, 칠판·CCTV 구역, 외부 두꺼비집을 배치했다. E 열쇠/양쪽 문 개방, F2 개발용 평면도. [최신 평면도와 구현 범위](docs/map/README.md).

첫 인게임 캐릭터·가게 디자인: [이미지와 설명](docs/design/README.md). 최신 06 버전은 할머니 본인 목소리 파동, 승인된 3m 이동/6m 범위 걷기 파동을 포함한다.

최신 맵: [조립식 평면도와 실행 설명](docs/map/README.md). E 전용 열쇠/문, F2 테스트 평면도. 매 Host 세션마다 연결과 시작 관제실이 바뀐다.
