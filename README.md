# Night Toy Store

스팀 출시를 목표로 개발하는 4인 협동 1인칭 공포게임.

밤의 장난감 가게에서 서로 다른 감각과 이동 제약을 가진 네 장난감이 협력하여 22:00부터 08:00까지 생존한다.

## 현재 상태

Unity 6000.6.4f1에서 로컬 이동·감각 테스트 코드 컴파일과 테스트 장면 생성을 확인했다. 실제 플레이·화면 검증, 4인 협동과 최종 디자인은 아직 완료되지 않았다.
